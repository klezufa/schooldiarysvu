# Сертификаты для профиля https

Сюда кладутся `fullchain.pem` (сертификат сервера и промежуточные, права 644) и `privkey.pem`
(закрытый ключ, права 600, владелец uid 101 — пользователь Nginx в образе). Файлы `*.pem` и `*.key`
в `.gitignore`: ключи в репозиторий не попадают.

Где взять сертификат — `docs/https.md`: внутренний центр сертификации для управляемых устройств
или публичный сертификат через DNS-01 (`scripts/renew-cert.sh`). Каталог можно вынести за пределы
репозитория переменной `TLS_DIR` в `.env`.

# Безопасность

- Пароли: Argon2id с параметрами из конфигурации; вход даёт одинаковый отказ для неизвестного логина и неверного пароля, попытки ограничиваются.
- Сессии: криптографически случайный токен, в БД только хеш; cookie `HttpOnly`, `SameSite=Lax`, `Secure` в HTTPS, ограниченный TTL и отзыв.
- CSRF: отдельный токен сессии передаётся в `X-CSRF-Token` для всех изменяющих методов; same-origin режим без permissive CORS.
- Авторизация: RBAC + object-level ABAC до чтения/изменения объекта. Прямая подстановка чужого UUID не даёт доступа.
- Файлы: лимит размера, определение MIME по содержимому, allowlist, случайный ключ, приватное хранилище, `Content-Disposition: attachment` и `nosniff`.
- Headers: CSP, frame denial, referrer policy, nosniff; HSTS только после проверки HTTPS-домена.
- Секреты: задаются окружением, не коммитятся и не выводятся в логи. Логи не содержат пароли, cookie, токены и тела чувствительных запросов.

`local-http` допустим только для разработки, изолированной сети или явно принятого пилота с `SESSION_COOKIE_SECURE=false`. LAN не исключает перехват и подмену трафика; этот режим не считается защищённым production. HTTPS обязателен для реальных данных при отсутствии явно принятого риска. Страница «Система» напоминает об этом системному администратору, пока включён `local-http`.

Корневой CA не устанавливается автоматически и не считается предполагаемым механизмом работы. Для управляемых устройств распространение выполняется через MDM/групповые политики; для личных устройств предпочтителен публичный домен с DNS-01.

## Эксплуатация

- **TLS** (профиль `https`): только TLS 1.2/1.3 и AEAD-шифры с прямой секретностью (Mozilla intermediate), без session tickets; порт 80 только перенаправляет. Backend не запускается в `https` без `Secure`-cookie. HSTS выключен по умолчанию и включается вручную по процедуре из `docs/https.md`: ошибка с сертификатом при включённом HSTS блокирует доступ без обходного пути.
- **Ключи**: закрытый ключ сервера создаётся на сервере и не покидает его (права 600, uid 101). Корневой ключ внутреннего ЦС хранится вне сервера и ограничен `nameConstraints` именем дневника. Ключ API DNS для Let's Encrypt — с правами только на записи одной зоны, в файле 600 вне репозитория; `renew-cert.sh` отказывается читать файл с более широкими правами.
- **Сеть**: PostgreSQL и backend не опубликованы на хост. Опубликованные порты Docker обходят ufw, поэтому доступ к ним ограничивается `BIND_ADDR`, ACL между VLAN и цепочкой `DOCKER-USER` (`docs/network.md`).
- **Резервные копии** содержат все персональные данные: доступ только у ИТ-администраторов, шифрованное хранилище, вторая копия вне сервера, срок хранения по положению школы. Секреты (`.env`, ключи TLS, ключ API DNS) в копии не входят.
- **Восстановление** завершает все сессии: иначе вернулись бы сессии, отозванные после даты копии. Пароли, сменённые после неё, снова действуют — при восстановлении после компрометации сбросьте пароли.
- **Перебор паролей**: блокировка на 15 минут после 5 неудач для пары «адрес — логин» и после 50 неудач с адреса по всем логинам (password spraying); ответ 429 сообщает срок (`Retry-After`). Неизвестный логин проверяется тем же хешем — время ответа не выдаёт существование пользователя.
- **Нагрузка на хеширование**: не больше `PASSWORD_HASH_CONCURRENCY` (2) хешей Argon2 одновременно, иначе утренний наплыв входов исчерпывал память контейнера; при долгой очереди — 503 с `Retry-After`. `GOMEMLIMIT` держит кучу Go ниже лимита контейнера.
- **Файлы**: тип определяется по содержимому, HTML и исполняемые файлы отклоняются, расширение имени приводится к реальному типу (текст под именем `.svg`/`.html` получает `.txt`), скачивание только `attachment` с `nosniff`.
- **Образы**: при сборке web пакеты Alpine обновляются (`apk upgrade`), PostgreSQL — актуальный минорный выпуск 17.x; проверка — Trivy (`docs/security-audit.md`).
- **Журнал эксплуатации** (`maintenance_events`) пишется скриптами копирования и восстановления и виден только системному администратору; в нём нет персональных данных — только имена копий, размеры и причины ошибок.

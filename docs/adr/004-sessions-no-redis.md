# ADR 004: серверные сессии; без Redis и микросервисов

Статус: принято. Сессии хранятся в PostgreSQL, что позволяет отзывать их и не держать токены в localStorage. Для одного сервера это просто и достаточно. Redis, Kafka и микросервисы не добавляются без измеренной потребности; внутренние уведомления MVP работают на PostgreSQL.
